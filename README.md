# Pulsar Fitness Centre — Website

A modern, dark-themed gym website built with React + Vite.

## Tech Stack
- React 18
- Vite 5
- Lucide React (icons)
- Google Fonts (Bebas Neue, Barlow Condensed, Inter)

## Sections
- **Hero** — Full-screen landing with stats
- **About** — Story, values, and skill bars
- **Programs** — 6 training programs with details
- **Facilities** — Amenities and equipment list
- **Pricing** — 3 membership plans with monthly/quarterly/annual toggle
- **Contact** — Contact info, enquiry form, and map link
- **Footer** — Links, timings, and contact details

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
